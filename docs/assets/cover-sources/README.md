## Preservation and future work

- Keep every inventoried original, generated source and frozen version in place.
  Make new revisions separately. Do not resave an original to apply an edit.
- Before editing, run `python3 docs/assets/cover-sources/verify.py`. It reads files
  and reports missing/changed bytes; it never repairs, overwrites or updates hashes.
- Historical `build.py` scripts can write into saved-version folders. Inspect and
  redirect outputs before reusing them. No builder was run for this inventory.
- Add each new asset and its source relationship to the manifest when created;
  record intentional replacements separately rather than silently accepting drift.
- Retained local photographs/stills are sufficient for the selected compositions.
  External camera paths and seek times are provenance, not checked or required
  drive dependencies. Original long videos have not been duplicated into this set.
- This is an index and integrity check, not an independent backup. It does not
  establish a final print master. A layered working master now exists for the cream
  V1 development, with separate graphic lettering, ribbon and stickers. Photographic
  resolution remains about 151 dpi at 185 × 240 mm; native live type and final print
  resolution remain separate production work. Earlier numbered covers remain frozen.

The manifest deliberately includes historical trials within this numbered-cover
development, so an intermediate original is not mistaken for disposable preview
material. Older selected G2/B5 and A4 sources remain in the parent asset registry.
