# Vegetable-guide pH and liming changes

Draft for review — 2 November 2026. Twelve guides; sixteen changes. Current book folios are retained. No main-book or canonical gardening data changes.

## Asparagus — page 15

**Before:** Choose sunny, sheltered, well-drained soil. Add compost or rotted manure; lime very acid ground if needed. Improve heavy-ground drainage or use a raised bed.

**Proposed:** Choose sunny, sheltered, well-drained soil. Add compost or rotted manure; lime only if a soil test shows a need. Improve heavy-ground drainage or use a raised bed.

Reason: Make the basis for deciding explicit.

## Bean, Broad — page 19

**Before:** Sun; moist, drained soil without last year’s beans. Lime very acid soil to pH 6.5.

**Proposed:** Sun; moist, drained soil without last year’s beans. About pH 6.5 suits the crop; test before liming.

Reason: Keep the pH preference without making it an automatic liming target.

## Bean, French — page 21

**Before:** Warm, sheltered sun; light, well-drained soil. Add compost or rotted manure; avoid cold, wet clay. Lime only if too acid.

**Proposed:** Warm, sheltered sun; light, well-drained soil. Add compost or rotted manure; avoid cold, wet clay. Test before liming acid soil.

Reason: Require a check before treatment.

## Bean, Runner — page 23

**Before:** Use sunny, sheltered, rich ground that holds moisture but drains well. Lime acid soil if needed towards pH 6.5.

**Proposed:** Use sunny, sheltered, rich ground that holds moisture but drains well. About pH 6.5 suits the crop; test before liming.

Reason: Keep the pH preference without automatic treatment.

## Beetroot — page 27

**Before:** Use previously manured ground or add autumn compost. Lime acid soil towards pH 6.5; feed poor ground if needed.

**Proposed:** Use previously manured ground or add autumn compost. About pH 6.5 suits the crop; test before liming. Feed poor ground if needed.

Reason: Retain the crop preference and conditional feeding; qualify liming.

## Broccoli — page 29

**Before:** Choose sunny, firm, fertile soil. Prepare in autumn with compost or well-rotted manure if soil is poor; lime only if needed.

**Proposed:** Choose sunny, firm, fertile soil. Prepare in autumn with compost or well-rotted manure if soil is poor; lime only if a soil test shows a need.

Reason: Make the decision explicit; the clubroot table already says testing is needed and lime is not a cure.

## Brussels Sprouts — page 31

**Before:** Lime acid soil if needed. Keep sprout plants clear of weeds; catch crops such as lettuce can use wide gaps while the plants are small.

**Proposed:** Lime only if a soil test shows a need. Keep sprout plants clear of weeds; catch crops such as lettuce can use wide gaps while the plants are small.

Reason: Make the decision explicit; retain the separate clubroot caution.

## Cabbage — page 33

**Before:** Add organic matter and lime acid ground only if needed.

**Proposed:** Add organic matter; lime only if a soil test shows a need.

Reason: Bring the reminder into line with conditional soil advice.

**Before:** Use fertile, firm soil. Lime acid ground if needed; tread firm and rake lightly. Collars or fine mesh guard against cabbage root fly.

**Proposed:** Use fertile, firm soil. Test before liming acid ground; tread firm and rake lightly. Collars or fine mesh guard against cabbage root fly.

Reason: Carry the test requirement into the main instructions.

## Carrot — page 37

**Before:** Follow a previously manured crop. Avoid fresh manure, which encourages forking; lime acid soil in winter and prepare a fine seedbed.

**Proposed:** Follow a previously manured crop. Avoid fresh manure, which encourages forking; test before liming and prepare a fine seedbed.

Reason: Remove the suggestion of a routine winter treatment; retain the approved fresh-manure qualification.

## Lettuce — page 65

**Before:** Avoid acid soil.

**Proposed:** Check before liming.

Reason: Make the reminder an action rather than a blanket warning about acidity.

**Before:** Lime if necessary and improve heavy clay with compost.

**Proposed:** Test before adding lime; improve heavy clay with compost.

Reason: Explain how to decide whether lime is necessary.

**Before:** Lime acid soil towards neutral; compost heavy clay repeatedly. Allow room under fleece/cloches for early growth.

**Proposed:** Test before liming towards neutral; compost heavy clay repeatedly. Allow room under fleece/cloches for early growth.

Reason: Retain the existing preference but require a check before correction.

## Potato — page 77

**Before:** Fertile, slightly acid soil with rotted compost/manure. Rotate; avoid liming.

**Proposed:** Fertile, slightly acid soil with rotted compost/manure. Rotate; avoid fresh lime.

Reason: Make the crop-specific timing clear, rather than imply that a rotation bed can never be limed.

**Before:** Avoid liming; keep soil moist as tubers form.

**Proposed:** Avoid fresh lime; keep soil moist as tubers form.

Reason: Retain the common-scab and moisture caution with clear timing.

## Radish — page 79

**Before:** Spring sun; light summer shade. Lime acid soil if needed. Winter types need humus-rich drainage.

**Proposed:** Spring sun; light summer shade. Test before liming acid soil. Winter types need humus-rich drainage.

Reason: Make the test requirement explicit; retain the existing ACID SOIL table entry.
