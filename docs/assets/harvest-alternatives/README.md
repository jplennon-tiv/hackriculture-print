# Harvest arrangements 02–07

Reusable photographic vegetable artwork from the six alternative cream covers for *The Vegetable Guru*. Each arrangement has an upper and a lower group. The filenames follow the numbering in the [cover comparison](../../publication/cover-versions/version-1-1/harvest-light-review/README.md).

- **[originals](originals/)** contains twelve full-resolution, transparent 2172 × 724 px PNGs. They are byte-for-byte copies of the generated artwork.
- **[with-cover-shadows](with-cover-shadows/)** contains the same twelve groups with the final cast shadows and shading on neighbouring vegetables. These transparent PNGs are cropped to the visible artwork and shadows at cover resolution. They can be placed directly on another background.

The [asset record](ARTWORK.json) identifies both copies, their checksums and their placement in the review cover. The [generation record](../../publication/cover-versions/version-1-1/natural-harvest-trials/ARTWORK.json) holds the original prompts.
