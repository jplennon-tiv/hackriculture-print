## Opening pages

The first visual check covered folios 1, 4, 5, 7, 9, 99 and 147. The photo gaps work best in the two full section openers, where the larger tiles can show individual subjects. The Techniques grid uses original views of the beds, greenhouse and compost jobs. The first Troubles grid uses generated aphids, a slug and powdery mildew alongside a genuine mesh-covered bed. The generated symptom details are section-opening artwork.

The existing copy, contents entries, 1991 photograph and three how-to panels all read in the new layouts. The amended title page adds a narrow gutter between adjoining photographs. The second contents page pairs peppers with a salad colander to vary the colours. The amended Troubles page clears the fragment of the original illustration that showed through the first proof.

The later p7 colander close-up also advances. Bare-handed harvesting and the worn metal bowl read naturally. The masonry, paving and aluminium greenhouse frame agree with the home camera views. This second tile is a reconstructed moment.
