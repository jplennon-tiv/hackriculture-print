# Photographing John’s allotment

Use this reference for allotment scenes in *The Vegetable Guru*. Keep John’s home garden, his allotment and any illustrative garden separately identified in the source register.

## Find the camera position

1. Identify the bed, season and direction required for the illustration. Start with the original photograph or video frame nearest that viewpoint. Compare the opposite view before composing a new angle.
2. Orient the March plan with the shed end at the top. John’s shed is pale green. Square slabs beside it measure 45 × 45 cm. The brown shed and the metal hoops across the grass path are on the neighbour’s plot. The barrel beside the covered beds and the water butt beside the shed door are different landmarks.
3. Use B01 (clip 0018, 02:04) for the finger paths, A04 (02:30) for the slabs beside the shed, and A06 (03:00) looking towards the barrel. Compare A06 with A02 (clip 0017, 02:15), looking the opposite way. The grass path and hoops switch sides in the image when the camera turns. See Working Map 03, pages 2, 4, 5 and 6. Working Map 02 preserves the earlier comparison.
4. Use the Blender model to choose a sightline. Check the background, roofline, bed edges and planting against a real frame before describing a view as John’s plot. Mark obscured boundary sections or approximate camera positions explicitly. Treat generated illustrations and the rectified ground patches as derivatives.
5. For each new still record the original filename, drive-relative path and time from the beginning of the original clip. If using a trimmed clip, record its start offset. Retain a clean frame alongside any cropped or annotated version.

## Fit the picture to the book

Work to the existing picture slot and crop. For a pair of activities, use two distinct pictures with a visible gutter where approved. Preserve the text and labels and inspect the complete page at print size. Match the tools, supports, clothing and working height visible in John’s material.
