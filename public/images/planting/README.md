# Installed planting artwork

Approved transparent illustrations supporting all 44 active vegetable layouts.
`src/print/plantingIllustrations.ts` owns scene selection and size limits.
Captions live in the shared master’s `print_planting` companion; measurements
resolve from live master paths in the chosen units. Preserve artwork, proportions
and existing size limits. Reused scenes intentionally remain available.

Historical drafts and rollout proofs were removed in the 24 September cleanup.
Git retains their source history; current implementation is documented in
`DEVELOPMENT.md`. Do not regenerate artwork as part of routine checks.

Onions and Shallots gained four method-specific illustrations on 1 October 2026:
`seed-sow-v1`, `seed-space-v1`, `set-tip-v2` and `set-growth-v1`. John approved the
seed/set sketch and approved the final changes, including the four illustrations
and both A4 proofs, on 1 October. Generation attribution, source decisions and file hashes
are in `docs/onion-planting/SOURCES-AND-ART.json`. The two earlier onion scenes
remain because the approved 30 September reference proofs still use them.
