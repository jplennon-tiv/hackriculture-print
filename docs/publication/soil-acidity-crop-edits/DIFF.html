Vegetable guides: pH and liming

Sixteen proposed wording changes across twelve guides. Deleted words are marked in the left column; additions are highlighted on the right. These are complete affected paragraphs, checked against the current book. Both unit editions have revised proofs.

The other 32 guides retain their existing wording. Soil preferences, pH values and useful deficiency warnings remain. Existing brassica clubroot entries already say to test before liming and that it is not a cure. The new Techniques page explains the general method; no provisional page reference has been added to crop text.

Asparagus page 15

Revised pages · imperial · metric · Highlighted proof

Before

Choose sunny, sheltered, well-drained soil. Add compost or rotted manure; lime very acid ground if needed. Improve heavy-ground drainage or use a raised bed.

Proposed

Choose sunny, sheltered, well-drained soil. Add compost or rotted manure; lime only if a soil test shows a need. Improve heavy-ground drainage or use a raised bed.

Make the basis for deciding explicit.

Bean, Broad page 19

Revised pages · imperial · metric · Highlighted proof

Before

Sun; moist, drained soil without last year’s beans. Lime very acid soil to pH 6.5.

Proposed

Sun; moist, drained soil without last year’s beans. About pH 6.5 suits the crop; test before liming.

Keep the pH preference without making it an automatic liming target.

Broccoli page 29

Revised pages · imperial · metric · Highlighted proof

Before

Choose sunny, firm, fertile soil. Prepare in autumn with compost or well-rotted manure if soil is poor; lime only if needed.

Proposed

Choose sunny, firm, fertile soil. Prepare in autumn with compost or well-rotted manure if soil is poor; lime only if a soil test shows a need.

Make the decision explicit; the clubroot table already says testing is needed and lime is not a cure.

Carrot page 37

Lettuce page 65

Revised pages · imperial · metric · Highlighted proof

Before

Avoid acid soil.

Proposed

Check before liming.

Make the reminder an action rather than a blanket warning about acidity.

Lime if necessary and improve heavy clay with compost.
