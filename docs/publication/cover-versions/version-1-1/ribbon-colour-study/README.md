John liked the [kerning and spine](../front-spacing-and-spine/README.md) and requested lighter red, green and blue ribbon alternatives. This separate proof changes the editable ribbon fill on that master. The original gold (#F2CC35) is the reference. The five new fills are within 0.03 CIE L* of its sRGB/D65 value of 83.08. All use the preceding proof’s dark-green lettering.

Page one compares the six colours on the same harvest detail. Pages 2–6 show full wraps in coral red, pea green, sky blue, apricot and lavender. The [palette](palette.json) records each fill. John selected the original gold (#F2CC35) on 18 November. See the [completed cover design](../selected-gold-cover/README.md).

Run the [builder](build.py) with the project Node on PATH and the Python runtime used for the earlier wrap. It reads that saved editable front and wrap PDF. All six pages were rendered for review. Pixel comparison of each full wrap with the preceding proof found differences only in the diagonal ribbon corner. Each page retained the same panel dimensions and exact rear and spine text.
