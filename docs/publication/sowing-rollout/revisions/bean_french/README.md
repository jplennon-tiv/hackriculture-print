# French Bean one-off amendment

5 November 2026. [Review both editions](REVIEW.html). John approved this derivative on 5 November. The [approval record](APPROVAL.json) freezes both editions. The original full readers and PDFs remain available.

The Birds entry in Key risks replaces the vague “Birds can be a nuisance in
several ways” with:

> Pigeons can eat seedlings and peck young leaves. Crows may dig up seeds or pull out young plants.

The canonical Birds record mainly describes peas, broad beans and runner beans,
so its examples were not silently reassigned to French beans. The
[focused research note](../../../../../../hackriculture-resources/summaries/french-bean-birds/research-notes.md)
records the canonical/local checks, online sources, scope and remaining issue
with the existing table sign “Torn pods”. The requested Key risks expansion does
not change that table or canonical gardening records.

Under John's standing crop-review guidance, “Lime only if too acid” is removed
from Soil & preparation. All other prose is unchanged. The existing six-short/
three-long Quick facts arrangement fits and is retained, with all nine facts and
icons. Both units keep two 185 × 240 mm pages, folios 20–21, original artwork,
five varieties and all seven pest entries. Footer clearances remain 6.45 mm and
3.07 mm. The See also destination remains unchanged.

[Exact amendment and original proof hashes](../../../../../src/print/book/sowing-rollout/revisions/bean_french.json),
[layout evidence](checks/bean_french.json), [PDF checks](checks/bean_french.verified)
and [preservation checks](CHECKS.json) record the result. Both final PDF spreads
were visually inspected against the original review. Approved crop proofs,
canonical records, the full review PDFs and the main book are unchanged.

Reproduce only this derivative with `node scripts/sowing-rollout/build.mjs
--revision bean_french`, with Vite started through `start.command`, then
`scripts/sowing-rollout/finish.py --revision bean_french` in the bundled Python
runtime. An approval file in this revision directory prevents overwriting.
