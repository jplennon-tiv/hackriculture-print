# Crop-by-crop planting illustration briefs

15 September 2026. Proposed production plan, not an implemented widget. All 44 master keys are covered. Use the shared visual prompt and physical-size budgets in [DESIGN.md](DESIGN.md), with the crop-specific scene instructions below. Measurements are editorial checkpoints, not a second runtime database. Read the live source before generating or labelling an asset.

`S` below means `<crop_key>.sowing_and_planting`. Listed bindings are relative to S unless stated otherwise. Use the existing imperial/metric pair, retaining qualifiers. Method and notes remain authoritative for instructions not represented by numeric fields. The source review is targeted, not a claim that all values are RHS-verified; see [SOURCE-ISSUES.md](SOURCE-ISSUES.md).

## Layout and production conventions

- **C2:** compact two scenes, complete card target 70–90 mm at A4.
- **S2:** standard two scenes, target 90–110 mm.
- **S3:** three scenes, target 110–130 mm. If necessary combine related actions into two pictures, preserving the third action in text.
- Dimensions include captions, notes and any small code-drawn spacing plan. These are proposed budgets, not proven fits. All scenes are independently generated wide text-free vignettes; measurements, arrows and step numbers come from code later.
- Default asset names: `01-<action>-v1.png`, `02-<action>-v1.png`, optional `03-<action>-v1.png`, inside the master-key folder. Each numbered scene below supplies its action/prompt and alt-text basis.
- No route or unique advice is deleted merely to make room. Two scenes combine sow/cover or place/firm where appropriate, rather than omitting meaningful information. Preserve variant guidance as compact text, not extra artwork by default.
- 37 ordinary two-scene crops + six three-scene crops = **92 scene placements**. Mushroom adds a conditional pair = **94 potential placements**, before reuse. This is not 94 promised generation calls or approved assets.

## Existing page-space evidence

Read-only inspection of the existing 14 September imperial batch found nine three-page exports: aubergine, bean_runner, beet_leaf, capsicum, celeriac, florence_fennel, mushroom, pea and tomato_outdoor. These are baselines, not new render results, and may predate the current master hash.

If useful content cannot fit, use the documented text fallback; do not silently trim the right column. Keep current page-one artwork and accepted layout unchanged.
